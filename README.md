# Dimple_KreativeArts

A modern, responsive website created for **Dimple_KreativeArts**, a handmade crochet and customized creations business.

The website provides an online showcase for handmade products and allows customers to explore products and place orders directly through WhatsApp.

## 🌸 About the Project

Dimple_KreativeArts creates handmade crochet products, customized gifts, accessories, keychains, bouquets, décor items, and other creative handmade pieces.

This project was created to transform the business's existing product catalog into a dedicated, user-friendly website.

## ✨ Features

- 🏠 Modern homepage
- 🛍️ Product shop and collections
- 🔎 Product search
- 🗂️ Product categories
- 🏷️ Sale and discounted products
- 📦 Product detail pages
- 🛒 Shopping cart
- 💬 WhatsApp ordering
- 🎨 Custom order section
- 📱 Responsive design for mobile, tablet, and desktop
- 📞 Contact section
- ⚡ Fast and modern user interface

## 📱 Ordering

The website uses **WhatsApp** for customer orders instead of an online payment system.

Customers can select a product and contact Dimple_KreativeArts directly through WhatsApp to discuss their order.
